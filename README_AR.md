# خادم نقاط منصة العراق التعليمية

هذا الخادم البسيط يحفظ رصيد كل طالب في ملف JSON. يجب تشغيله على Render مع **Persistent Disk** وربطه بمسار `/var/data` حتى لا تضيع البيانات عند إعادة التشغيل.

## إعداد Render
1. ارفع محتويات هذا المجلد إلى مجلد باسم `points-backend` داخل مستودع GitHub (أو مستودع مستقل).
2. في Render اختر New + → Web Service واربط المستودع.
3. إذا كان الخادم داخل مجلد فرعي، اجعل Root Directory هو `points-backend`.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. أضف Environment Variable باسم `ADMIN_KEY` وضع قيمة سرية طويلة لا تشاركها مع الطلاب.
7. أضف Persistent Disk، Mount Path `/var/data`، ثم أضف Environment Variable باسم `DATA_DIR` وقيمته `/var/data`.
8. بعد النشر افتح `https://YOUR-SERVICE.onrender.com/api/health`؛ المفروض يظهر `{"ok":true,...}`.
9. انسخ رابط الخدمة الأساسي، بدون `/api/health`، إلى إعدادات ربط الخادم في منصة الطالب والمسؤول.
10. في خانة مفتاح المسؤول في إعدادات المنصة، أدخل نفس قيمة `ADMIN_KEY`؛ احتفظ بها عند المسؤول فقط ولا ترسلها للطلاب.

## ملاحظات مهمة
- هذا الخادم ينفذ إرسال النقاط واسترجاع الرصيد فقط؛ لا يضيف مسارات الذكاء الاصطناعي أو الألعاب أو المتجر.
- استخدم Persistent Disk حتى تبقى الأرصدة محفوظة.
- حماية لوحة الإدارة في واجهة HTML ليست كافية وحدها؛ هذا الخادم يطلب `x-admin-key` لعملية إرسال النقاط.
