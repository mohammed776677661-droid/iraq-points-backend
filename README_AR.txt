تحديث منصة العراق التعليمية

الملف: index.html

التعديلات:
- تطوير واجهة روابط الدعوة وإظهار إحصائيات محلية.
- إصلاح قسم التحفيز ليعرض نصائح فعلية دون الاعتماد على اتصال الذكاء الاصطناعي.
- إضافة اختيار صورة من الاستوديو في شاشة الإشعارات وعرض الصورة مع الإشعار.
- محاولة تفعيل الأكواد عبر مسار الخادم /api/access-codes/verify عند ضبط رابط الخادم.
- إضافة مدخل لإحصائيات الإحالات في لوحة الإدارة.

مهم:
هذه نسخة واجهة. الإحالات والنقاط والأكواد والإشعارات التي يجب أن تعمل بين أجهزة جميع الطلاب تحتاج تنفيذ مسارات API في Backend وقاعدة بيانات مشتركة، ثم نشر Backend مع تخزين دائم. المسارات المتوقعة:
POST /api/access-codes/verify
GET /api/referrals/:studentId
GET /api/admin/referrals (محمي بمفتاح المسؤول)
POST /api/referrals/claim (لمنح 10 نقاط مرة واحدة بعد تسجيل طالب جديد)
POST /api/notifications (حفظ الإشعار للطلاب)

لا تضع مفتاح مسؤول أو مفتاح AI داخل ملف HTML. لا تعتبر الإحصائيات المحلية إثباتاً لعدد الطلاب الفعليين؛ يمكن حذفها من المتصفح. افحص الخادم قبل نشر النسخة للطلاب.
