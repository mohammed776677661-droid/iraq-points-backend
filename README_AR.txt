تحديث منصة العراق التعليمية

الملف: index.html

يتضمن تحسينات للألعاب والإشعارات واختيار ملفات من الاستديو.
تنبيه مهم: الإشعارات وبيانات المنصة في هذه النسخة تُحفظ محلياً في المتصفح. اختيار فيديو من الاستديو ينشئ رابطاً محلياً للجهاز الحالي فقط، ولا يجعل الملف متاحاً لبقية الطلاب. لتوصيل الإشعارات والملفات لجميع الطلاب يجب ربط API وقاعدة بيانات وتخزين ملفات سحابي. لا تنشر مفاتيح الإدارة أو مفاتيح API داخل HTML.

للتجربة: استبدل index.html في مستودع الواجهة ثم انتظر نجاح النشر، واختبر الألعاب والإشعارات.
